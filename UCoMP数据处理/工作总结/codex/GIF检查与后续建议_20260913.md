## 观察与解释范围

- 正波数外传在许多位置明显更强；两侧均有局部倾斜增强或功率团，但并非每一帧都存在可完整拟合的脊线。
- 约 2–3 mHz 的横向增强在多个中间时刻也存在，尤其部分较小 x 的空间块，因此不能全归因于时间端点。
- 第 0 与 134 帧形态相似。notebook 使用 (120,180,135) 输入，仅空间方向补零，时间仍为未填充的 135 帧。首尾相似与时间周期回绕相符，但不是单凭图像就能证明的因果关系。需要时间 padding 对照。
- 当前 k=0.05–0.15 rad/Mm，f=2–10 mHz。对示例速度 0.37 Mm/s，f=2 mHz 对应 k≈0.034，f=3 mHz 对应 k≈0.051。低频脊线中心可能在当前波数范围外或边缘，不能预期总能观察完整斜脊线；此例不代表实际速度已测定。
- 当前 k0=2、omega0=4。主高斯包络时间尺度约 omega0/(2πf)，2 mHz 时约 318 s，3 mHz 时约 212 s。空间主包络尺度约 k0/k，k=0.05 时约 40 Mm（12.4 像素）。这些是尺度估计而非正式 COI 阈值。5×5 分块是系数统计单元，不是独立的 5×5 原始数据分析窗；邻块及连续帧相关。

## 优先工作

1. 对代表性空间块与波数/频率做时间零填充收敛对照；先不重算完整巨型输出。原始边界不确定性在补零后仍存在。
2. 在谱图叠加示例速度线，标出各频率是否有完整的波数峰搜索范围；靠边峰标记截断。
3. 中间时间、边界影响较小的区域，区分倾斜脊线候选与水平频带候选。不要对所有频率强制提峰，也不要直接删除所有低频增强。
4. 对仅含外传波、有限包络波、双向波与背景振荡，使用相同 stmorlet 参数作少量合成对照；通过后再定内传掩膜。
